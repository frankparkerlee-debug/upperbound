# Upperbound

**A human performance clinic · Online.** Standalone telehealth venture — physician-guided
pathways to more capacity, built for LegitScript certification.

## Contents

- **[mockup.html](mockup.html)** — the working homepage prototype (v19). Fully
  self-contained single file: open it in any browser. Interactive pathway finder,
  menu-board pathways, energy-curve slider, 12-week arc scrubber, altitude rail,
  clickable symptom ticker, comparison table, FAQ, placeholder member stories.
- **[STRATEGY.md](STRATEGY.md)** — venture strategy: thesis, regulatory window,
  competitive map, wedges, pricing. Amended for the no-diagnostics and
  pathways-not-medications decisions.
- **[BRAND.md](BRAND.md)** — brand book: name, logo device (the overbar), voice,
  palette, type roles.
- **[PLATFORM.md](PLATFORM.md)** — build architecture reference (Next.js/Prisma
  chassis, vendor landscape).
- **direction.html** — early typographic direction (v1, historical).
- **img/** — AI-generated art direction imagery (placeholders only — replace with a
  commissioned shoot before launch; never ship AI people).

## Ground rules baked into the prototype

- **Pathways, not medications** — no compound names, no vials, no dosing on any
  marketing surface. Built to the LegitScript standard.
- **No claims** — interactive visualizations are labeled illustrative; no outcome or
  marker claims anywhere.
- **No prepay** — monthly, cancel in two clicks; the anti-lock-in stance is the brand.
- All figures, prices, stories and badges are placeholders pending launch.
